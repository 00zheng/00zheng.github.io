# 00zheng.github.io

Simple responsive website template.

## Files
- `index.html` page structure
- `styles.css` visual theme and responsive layout
- `script.js` reveal-on-scroll animation

## Quick start
Open `index.html` in your browser.

## Customize
- Change brand name, text, and links in `index.html`
- Adjust colors in `:root` variables inside `styles.css`
- Remove or tune motion in `script.js`
